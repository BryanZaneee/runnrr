# Runnrr workstation references

The September 22, 2026 workstation replaces all earlier repository UI pages.

- `screenshots/`: the two supplied workstation screenshots.
- `source/Runnrr Workstation.dc.html` and `source/support.js`: the original interactive design export, preserved as reference only.
- `source/uploads/RUNNRR RESEARCH.pdf`: visual research containing Hermes reference screenshots.
- [Feature inventory](../plans/runnrr-feature-inventory.md): the accompanying feature inventory.

The live implementation is `web/`. It retains the supplied layout, light palette,
orange accent, and typography, with semantic controls and responsive navigation.
The editor toolbar in the reference screenshots is not part of the product.

Reference conversations, integrations, attachments, and actions are simulated in
the export. They do not run in the live UI. Runtime profiles and streaming chat
are live; conversations, pins, and drafts are temporary. Missing capabilities
are explicitly unavailable. The existing backend profiles remain unchanged.
